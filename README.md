# 聊天生图

酒馆扩展。角色回复写完之后，用你现在的聊天模型单独写一段 NovelAI 提示词，接在「正面提示词.中」后面，发给 [idlecloud](https://api.idlecloud.cc) 中转站，图挂回这一楼下面。

不改酒馆的聊天补全，也不做纯生图。

## 安装

仓库根目录就是本文件夹，`manifest.json` 必须在根上。

酒馆 → 扩展 → 安装扩展，粘贴：

```
https://github.com/grooosex/nano-chat-image
```

跑酒馆的那台机器要装 Git。仓库必须是公开的。装完刷新页面。

## 使用

1. 打开扩展「聊天生图」，打开总开关。
2. 填写中转站地址和 API Key，点测试连接。Key 只存在你本机的酒馆设置里，不要提交进这个仓库。
3. 写词默认走酒馆当前连接，但是一条干净请求，不带角色卡和预设。也可以改成专用 OpenAI 兼容接口。
4. 正面提示词前 / 中 / 后、负面、模型、步数这些，按当前角色卡分开存。没单独存过的角色用「默认模板」。
5. 角色楼生成完（含酒馆再写一版）会自动出图。只是左右翻已经写好的几版，不会重新画，每版留自己的图。

图下面四个按钮：

- 重新生成：沿用这一张的中段，换种子再画
- 换提示词生成：按这一楼对白重写中段再画
- 下载
- 自定义修改：改接到中段后面的那段

总开关关掉之后不再写词、不再请求中转站。已经生成的图还留着。

参考图只用参数里上传的那张。中转站大约 20 秒才能再交一次，面板会显示「可生图」或倒计时。
